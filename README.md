Product Management System


Here is the steps to run the project on your system

Step 1: Take a clone by following below link: 
        - https://github.com/nehapanchal2606/Product_Management_System



Step 2: Open project in Code editor. Then go into ProjectManagement folder directory where manage.py and requirement.txt file are located.

Step 3: Install all Required library as listed in requirements.tsxt by following the below command:
      - pip3 install -r requirements.txt


Step 4: Run the server by following below command and check project
      - python3 manage.py runserver
